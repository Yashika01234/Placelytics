## 🌷 What is Placelytics?

A dark-themed, SaaS-style analytics dashboard that explores **who gets hired, by whom, for how much, and why**.
It goes past the usual "placement %" chart with funnels, skill-gap analysis, risk detection and a what-if simulator.

📸 *(add a dashboard screenshot here: `docs/overview.png`)*

## 🎀 Features

| | Module | What it answers |
|---|---|---|
| 🕵️ | **Recruiter Intelligence** | Who hires, how much, which skills do they want, is hiring concentrated? |
| 🧩 | **Skill Gap Analysis** | Which skills do recruiters demand but students lack? |
| 🪣 | **Placement Funnel** | Eligible → applied → shortlisted → interviewed → selected (plus a Sankey of drop-offs) |
| 💰 | **Salary Intelligence** | Percentiles, Gini inequality, outliers, top-10% value share |
| 🏫 | **Department Benchmarking** | Branch × year comparisons with YoY change |
| 🎓 | **Internship Impact** | Placement odds with vs without internships, adjusted for CGPA (Mantel-Haenszel) |
| 🚨 | **Placement Risk** | Branches and funnel stages with worrying trends |
| 🔮 | **What-if Simulator** | "What if 20% more students cleared interviews?" |
| 🤖 | **Predictive Model** | Logistic regression + gradient boosting, validated on a held-out *future* year |

Plus 🔍 filters (year, branch, company, industry, salary), ⬇️ CSV downloads, and a 🧪 **SQL Lab** tab that shows the queries behind the numbers.

## 🚀 Quick Start

```bash
git clone https://github.com/Yashika01234/Placelytics.git
cd Placelytics

python -m venv .venv
.venv\Scripts\activate            # Windows
# source .venv/bin/activate       # macOS / Linux

pip install -r requirements.txt
python run_pipeline.py            # generate → clean → validate → SQLite
python -m pytest -q               # run the tests
streamlit run app.py              # open http://localhost:8501
```

> 💡 The data builds itself on first launch, so `streamlit run app.py` alone also works.

## 🧪 About the synthetic data

- 🎓 ~3,760 students · 5 batches (2020–2024) · 6 branches
- 🏢 48 fictional recruiters across 8 industries · 212 drives · ~10k applications
- 🔗 Realistic relationships: ability drives CGPA, skills and internships; recruiters shift hiring over the years
- 🧹 Deliberately messy: missing values, impossible CGPAs, duplicates, rupee-vs-LPA typos, real salary outliers
- ♻️ Fully reproducible: `python run_pipeline.py --seed 42`

## 🌟 Sample insights (seed 42, synthetic)

- 📈 **73.2%** of placement-seeking students placed · median package **9.1 LPA** vs mean 10.4 (right-skewed)
- 🏆 2024 branch gap: **CSE 88.4%** vs **ME 64.2%**
- 🎓 Internships: placement rises from **58% (none) to 97% (3+)**, and the CGPA-adjusted odds ratio is **~3.0×**
- 🧩 Biggest skill gaps: **Communication, Excel, SQL**
- 💸 Top 10% of placed students hold **~20%** of total package value (Gini 0.25)

## ⚠️ Honest limitations

- Synthetic data encodes the relationships I chose, so it validates the *pipeline*, not the real world.
- The internship effect is an association, not proof of causation.
- The simulator is scenario analysis, not a forecast. It is anchored to the observed baseline and doesn't model salaries.
